# 萃刻 iOS 首版验收

本清单是待执行的原生验收步骤，不是通过记录。执行时填写 Xcode、SDK、设备、系统版本和证据位置。

## 构建基线

- [ ] 打开 Cuike.xcodeproj，无缺失文件或外部依赖。
- [ ] 主应用与 Widget 扩展均能编译；确认部署下限 iOS 17。
- [ ] 运行4项 SwiftData 集成测试与2项 UI 测试，保存 xcresult。
- [ ] 模拟器冷启动；没有白屏、报错或崩溃。

## 主业务闭环

- [ ] 首次启动3袋豆、3条手记，平均4.3；再次启动不重复播种。
- [ ] 配方15g ×16=240g；改18g后288g，保存并重启后保留。
- [ ] 同一时间最多一个未完成会话，无暂停按钮。
- [ ] 阶段切换在30秒、120秒、180秒；目标分别45g、240g、停止注水。
- [ ] 切后台60秒再回来，计时继续；结束后停在待品饮。
- [ ] 强制关闭应用并重新打开，恢复同一 sessionID，不生成第二杯。
- [ ] 前台调整系统时间，出现确认结束/放弃提示。
- [ ] 提前结束须确认，历史保留实际时长和结束原因。
- [ ] 未选星级不能保存；200字以内笔记可存，201字提示修正。
- [ ] 新增5星后4条手记、均分4.5；重复点保存不增多。
- [ ] 编辑豆名、调整原配方，不改变过去那杯的名称和参数。
- [ ] 编辑评分后均分同步；删除记录有确认且统计同步回退。
- [ ] 历史「再冲一杯」复用当时参数，但只进入待开始页。

## 豆档案与识别

- [ ] 空豆名/超过40字不能保存；取消不创建记录。
- [ ] 搜索、处理法筛选、归档/恢复正常；全部归档时显示空态。
- [ ] 无引用自建豆可删；历史引用豆只能归档。
- [ ] 原创 sample-bean.png 实际执行 Vision 识别，保存前可查看原图和文字。
- [ ] 核对识别内容：Name、Origin、Process、Roast；字段缺失时不猜测。
- [ ] 无文字图片提示重试或手填；相册取消不新建档案。
- [ ] 真机扫描多行文字后人工确认；拒绝权限/设备不支持时仍可选图或手填。

## 系统延伸

- [ ] 真机两个目标签名和 App Group 一致，组件可读取最新保存配方。
- [ ] 小组件点击到正确配方，不自动开始；归档后旧链接有说明。
- [ ] 快捷指令「打开上次配方」在冷启动和热启动都有效，不自动计时。
- [ ] 开始冲煮后锁屏/灵动岛显示总倒计时；点击返回同一会话。
- [ ] 到期、提前结束、放弃后检查实时活动清理，不残留另一杯的内容。
- [ ] 系统禁用实时活动、没有灵动岛时，主流程仍正常。
- [ ] 偏好中授权本地通知后，后台到期能提示；拒绝后仍能使用主流程。
- [ ] 取消/提前结束会清除尚未触发的完成通知。
- [ ] 真机触感：参数档位、前台阶段变化、保存成功；关闭后不触发。
- [ ] 系统分享面板包含当时的配方和风味，不包含其他记录。

## 视觉与可访问性

- [ ] 与设计包对照：冲煮台、豆档案、识别确认、配方、计时、记录、历史。
- [ ] 深色和系统大字下文字可读，表单可滚动，主按钮可到达。
- [ ] 小屏机型无横向溢出；VoiceOver 控件有名称，图表有文字摘要。
- [ ] 开启减少动态效果后计时仍清晰，触感与阶段语义不受影响。
- [ ] iPad 基础布局可用；P2 双栏暂不计入首版验收。
